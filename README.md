# BlogNest

> Ideas Worth Sharing. Stories Worth Reading.

BlogNest is a responsive Blog Application frontend developed as part of my Codomax Digital Solutions Full Stack Web Development Internship.

## About the Project

BlogNest is a modern and responsive blog platform interface where users can explore blog content, create an account, log in, manage their dashboard, and create blog posts.

The current implementation focuses on the frontend development requirements of Module 1.

## Features

- Responsive Home Page
- User Login Interface
- User Registration Interface
- Responsive Dashboard
- Create Blog Interface
- Blog Title Character Counter
- Blog Content Character Counter
- Live Blog Preview
- Basic JavaScript Form Validation
- Responsive Navigation
- Mobile-Friendly Sidebar
- Responsive Design for Desktop, Tablet, and Mobile
